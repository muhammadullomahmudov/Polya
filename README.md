## Ishga tushirish

Bitta `index.html` fayl, server shart emas. GitHub Pages orqali chiqarish uchun:
Settings → Pages → Branch: `main`, papka: `/ (root)`.

Hozircha bu versiyada bronlar serverda saqlanmaydi: mijoz forma to'ldirganda sayt tayyor ariza matnini beradi,
u uni Telegram yoki telefon orqali murabbiyga yuboradi. Jonli jadval uchun backend (masalan, Firebase yoki Supabase) ulash kerak.
